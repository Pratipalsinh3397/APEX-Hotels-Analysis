# 🏨 APEX Hotels Data Analysis

## 📖 Project Overview

APEX Hotels operates multiple hotel properties across different cities and serves customers through various booking platforms. Managing hotel operations efficiently requires continuous monitoring of occupancy rates, revenue generation, room utilization, and customer satisfaction.

This project focuses on analyzing hotel booking and operational data to uncover valuable business insights. Using Python and data analytics techniques, the project performs data cleaning, preprocessing, and exploratory data analysis (EDA) to evaluate hotel performance across cities, properties, room categories, and booking platforms.

The insights generated from this analysis can help hotel management make informed business decisions to improve occupancy rates, maximize revenue, and enhance customer experience.

---

## 🎯 Business Problem

APEX Hotels collects large volumes of booking and revenue data from multiple properties. However, raw data alone does not provide actionable insights for business growth.

The goal of this project is to analyze hotel booking data and answer key business questions related to occupancy, revenue, customer ratings, and booking channels. The analysis aims to identify performance trends, operational inefficiencies, and revenue opportunities that can support strategic decision-making.

---

## 📊 Business Questions Addressed

### Occupancy Analysis

1. What is the average occupancy rate for each room category?
2. Which city has the highest average occupancy rate?
3. Is hotel occupancy higher on weekdays or weekends?
4. What was the occupancy rate across different cities during June 2022?

### Revenue Analysis

5. What is the total revenue generated by each city?
6. How does revenue vary month by month?
7. Which hotel properties generate the highest revenue?
8. How is revenue distributed across different booking platforms?

### Customer Analysis

9. What is the average customer rating for each city?

## 🧹 Data Cleaning & Preprocessing

The dataset underwent several preprocessing and validation steps before analysis:

- Removed records containing negative guest counts.
- Identified and handled outliers in revenue data.
- Checked for missing values and data inconsistencies.
- Validated booking capacity constraints.
- Identified cases where successful bookings exceeded room capacity.
- Created Occupancy Percentage (Occ%) as a business KPI.
- Merged and analyzed additional booking datasets.
- Performed data transformation for analytical reporting.
